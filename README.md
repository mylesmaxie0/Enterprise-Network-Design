# Enterprise-Network-Design

### Overview
This project simulates a production-grade enterprise network across two sites using EVE-NG with Cisco IOL routers and Layer 2/3 switches. The design prioritizes redundancy, scalability, and observability — with every major failure scenario tested and validated.
